\# Raw Data



The dataset used in this project is the \*\*Stellar Classification Dataset - SDSS17\*\*.



Source:

Kaggle — Stellar Classification Dataset - SDSS17



The raw CSV file is intentionally excluded from this GitHub repository using `.gitignore`.



The dataset contains observations from the Sloan Digital Sky Survey (SDSS) and is used to investigate the classification of astronomical objects into:



\- Stars

\- Galaxies

\- Quasars
