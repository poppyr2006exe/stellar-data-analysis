\# SDSS17 Data Dictionary



This document describes the variables contained in the SDSS17 stellar classification dataset.



| Variable | Description | Type | Initial use |

|---|---|---|---|

| `obj\_ID` | Object identifier | Identifier | Exclude from modelling |

| `alpha` | Right ascension | Numerical | Investigate |

| `delta` | Declination | Numerical | Investigate |

| `u` | u-band photometric measurement | Numerical | Investigate |

| `g` | g-band photometric measurement | Numerical | Investigate |

| `r` | r-band photometric measurement | Numerical | Investigate |

| `i` | i-band photometric measurement | Numerical | Investigate |

| `z` | z-band photometric measurement | Numerical | Investigate |

| `run\_ID` | SDSS observation run identifier | Identifier | Investigate |

| `rerun\_ID` | SDSS processing rerun identifier | Identifier | Exclude |

| `cam\_col` | Camera column identifier | Identifier | Investigate |

| `field\_ID` | SDSS field identifier | Identifier | Investigate |

| `spec\_obj\_ID` | Spectroscopic object identifier | Identifier | Exclude |

| `class` | Object classification: STAR, GALAXY or QSO | Categorical | Target |

| `redshift` | Redshift measurement | Numerical | Investigate |

| `plate` | Spectroscopic plate identifier | Identifier | Investigate |

| `MJD` | Modified Julian Date of observation | Numerical/Date | Investigate |

| `fiber\_ID` | Spectroscopic fibre identifier | Identifier | Investigate |
